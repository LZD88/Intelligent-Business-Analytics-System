# report-verification Specification

## Purpose

对用户可见的报告正文进行独立于生成模型的核验，防止有效证据旁出现不受支持的数字或因果判断；保留可复核的统计、计算过程及业务人工判断边界。

## Requirements

### Requirement: 正文可验证陈述
系统 SHALL 核验发现和建议中的数值是否来自对应证据或受控计算，并拒绝无支持的因果、收益承诺。报告 SHALL 返回核验状态、问题和人工判断边界。

#### Scenario: 伪造正文数字
- **WHEN** 模型引用有效单元格但正文填写不受支持的金额或比例
- **THEN** 系统要求修复，仍失败时仅提供通过核验的回退报告

#### Scenario: 不充分业务依据
- **WHEN** 数据只证明横向成本差异
- **THEN** 报告可建议复核明细但不能宣称故障原因或承诺节省金额
